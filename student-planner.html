FULL-STACK WEB APP

Student Planner

Aplikasi web personal untuk membantu mahasiswa mengelola jadwal, tugas, keuangan, tabungan, dan profil dengan sinkronisasi cloud antar perangkat.

Tentang Project

Student Planner adalah aplikasi web yang saya kembangkan untuk menyatukan kebutuhan akademik dan pengelolaan pribadi mahasiswa dalam satu dashboard. Aplikasi ini menggunakan Supabase sebagai backend sehingga data dapat tersimpan secara online dan digunakan dengan akun yang sama dari laptop maupun smartphone.

Fitur Utama

Authentication dan akun pengguna
Jadwal kuliah dan mata kuliah
Manajemen tugas aktif dan selesai
Multi-wallet, pemasukan, dan pengeluaran
Target tabungan terhubung dengan saldo dompet
Profil mahasiswa dan penyimpanan foto
Sinkronisasi data cloud dan Realtime
Responsive untuk HP dan desktop

Tech Stack

HTML CSS JavaScript Supabase PostgreSQL Supabase Auth Storage Realtime Vercel

Yang Saya Pelajari

Dari project ini saya belajar mengembangkan aplikasi dari frontend menjadi aplikasi full-stack, merancang struktur database PostgreSQL, mengamankan data menggunakan Row Level Security, menangani autentikasi, sinkronisasi antar perangkat, penyimpanan file, serta deployment dan integrasi GitHub dengan Vercel.

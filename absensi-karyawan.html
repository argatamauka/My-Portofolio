WEB APPLICATION

Absensi Karyawan

Website absensi pegawai dengan sistem kehadiran, foto, lokasi, dan rekap data bulanan.

Tentang Project

Absensi Karyawan adalah aplikasi web yang saya kembangkan untuk membantu pegawai melakukan absensi dengan lebih mudah. Sistem dibuat dengan tampilan sederhana agar tetap nyaman digunakan oleh pengguna yang kurang terbiasa dengan teknologi.

Fitur Utama

Check in dan check out
Foto kehadiran
Lokasi dan radius absensi
Rekap absensi bulanan
Dashboard admin
Responsive untuk HP

Tech Stack

HTML CSS JavaScript Apps Script Google Sheets

Yang Saya Pelajari

Dari project ini saya belajar membuat sistem yang lebih berorientasi pada kebutuhan pengguna, menghubungkan website dengan Google Sheets, mengelola data absensi, menangani validasi lokasi, serta membuat dashboard admin yang mudah digunakan.

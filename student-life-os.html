WEB APP PROJECT

Student Planner v1

Platform web pribadi untuk membantu mengatur kehidupan dan aktivitas mahasiswa.

Tentang Project

Student Planner v1 adalah aplikasi web yang saya kembangkan untuk membantu mengatur kehidupan mahasiswa dalam satu tempat. Project ini menggabungkan pengelolaan aktivitas, galeri pribadi, tugas, kalender, dan beberapa fitur lain yang mendukung kegiatan sehari-hari.

Fitur Utama

Manajemen aktivitas
Galeri foto pribadi
Kalender dan tugas
Admin Control Center
Responsive Design

Tech Stack

HTML CSS Laravel Livewire Vercel

Yang Saya Pelajari

Melalui project ini saya belajar bagaimana mengembangkan sebuah aplikasi secara bertahap, memperbaiki bug, membuat desain responsif, menggunakan Git untuk version control, serta melakukan deployment website ke production.
